# Alesyan Reservations: website booking widget (TEST MODE)

Standalone demo preview: https://alesyan-reservations.onrender.com/widget/alesyan-demo-malahide

Embed this launcher in any demonstration website:

```html
<iframe
  src="https://alesyan-reservations.onrender.com/widget/alesyan-demo-malahide"
  title="Alesyan Reserve — find a table (demo)"
  loading="lazy"
  width="100%"
  height="490"
  style="max-width:490px;border:1px solid #d9e6e2;border-radius:16px"
></iframe>
```

The launcher uses Alesyan’s original design, collects only date/time/party size, and opens Alesyan’s booking page. It does not accept personal information or payment details inside the iframe. It targets a **fictional demonstration venue**, not a real Gourmet Food Parlour booking.

**Not ready for a public restaurant launch**: production venue onboarding, true multi-tenant public booking endpoints, domain/origin configuration, GDPR notices, spam/bot mitigation, booking cancellation/confirmation and payment handling must be completed before handing this code to a real restaurant.

Do not reuse OpenTable's embed script or branding. This widget is independent.
